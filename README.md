# Portfolio – Armando Makosso

Portfolio personnel d'Armando Makosso, étudiant en **BTS SIO option SLAM**, présentant
son parcours, ses compétences, ses projets et ses expériences dans le domaine du
développement web et de l'informatique.

Le design s'inspire de l'interface **PlayStation 5** (thème sombre, dégradés bleus,
cartes lumineuses) et intègre des **animations de code** (fond « pluie de code »,
effet machine à écrire, apparitions au défilement).

## 🚀 Aperçu

- **Page d'entrée** : `index.html`
- **Accueil** : `accueil.html`
- **Pages** : À propos, Compétences, Expériences, Projets, Contact 

## 🛠️ Technologies

- HTML5
- CSS3 (Flexbox, Grid, animations, responsive)
- JavaScript (Canvas, IntersectionObserver)

## 📁 Structure du projet

```
Portfolio.Pro/
├── index.html            # Page d'entrée
├── accueil.html          # Accueil
├── style.css             # Styles globaux (thème PS5 + animations)
├── script.js             # Gestion du CV
├── animations.js         # Animations de code (fond, machine à écrire, fondu)
├── assets/
│   ├── favicon.svg
│   ├── cv/               # CV téléchargeable
│   └── images/           # Photos et visuels
└── pages/
    ├── apropos.html
    ├── competences.html
    ├── experiences.html
    ├── projets.html
    └── contact.html
```

## ▶️ Lancer le projet en local

Aucune installation requise : ouvrez simplement `index.html` dans un navigateur.

Pour un rendu optimal (chemins, iframe du CV), vous pouvez utiliser un petit serveur local,
par exemple avec l'extension **Live Server** de VS Code, ou en ligne de commande :

```bash
# Python
python -m http.server 8000
# puis ouvrez http://localhost:8000/index.html
```
